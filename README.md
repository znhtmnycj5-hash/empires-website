# Empire Frontend Prototype

Статический интерактивный frontend-макет сообщества Mount & Blade: Napoleonic Wars.

Страницы:
- index.html — главная
- regiments.html — полки
- campaigns.html — кампании
- ranking.html — рейтинг
- forum.html — форум
- alliances.html — союзы

Открыть index.html в браузере.


## Visual skin v3
Добавлены декоративные изображения из утвержденного визуального концепта: header-art, hero-art, crest-art и footer-art. Иконки навигации сделаны через CSS, чтобы макет оставался автономным.
