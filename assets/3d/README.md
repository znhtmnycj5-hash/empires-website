# Кавалерист — 3D assets

Эта папка зарезервирована под реальные GLB/GLTF-модели игры.

Ожидаемые файлы:
- player-russian-cavalry.glb — русский кавалерийский офицер
- british-infantry.glb — британский пехотинец Waterloo
- hussar.glb — вражеский гусар

Модели подключаются к Three.js runtime в cavalier.html автоматически, если файлы присутствуют.

Источники выбранных моделей:
- Waterloo British Infantry — Andy Woodhead / CC Attribution
- Chief Officer of the Cavalry Guard Regiment — 1812panorama / CC0
- Hussar — Andy Woodhead

Не помещайте сюда файлы, на которые у проекта нет права распространения. Для Sketchfab-моделей сначала скачайте их через страницу автора/Sketchfab с учётом лицензии.
